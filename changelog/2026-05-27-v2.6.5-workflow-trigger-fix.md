# v2.6.5 - 修复 GitHub Actions workflow 触发 Pages 部署权限问题

**日期**：2026-05-27

## 需求背景

`fund-info-sync.yml` 中通过 `curl` 调用 GitHub API 的 `workflow_dispatch` 接口来触发 `pages-deploy.yml`，但 `GITHUB_TOKEN`（默认 token）受 GitHub 安全限制，无法跨 workflow 触发其他 workflow，导致返回 403 错误：

```json
{
  "message": "Resource not accessible by integration",
  "status": "403"
}
```

## 实现方案

采用 GitHub Actions 原生的 `workflow_run` 事件替代 `curl` dispatch 方式：

1. **`pages-deploy.yml`**：新增 `workflow_run` 触发器，监听 `Fund Info Sync` workflow 完成事件
2. **`pages-deploy.yml`**：添加 `if` 条件判断，仅在 sync workflow 成功（`conclusion == 'success'`）时才执行构建部署
3. **`fund-info-sync.yml`**：移除失败的 `Trigger Pages Deploy` curl 步骤

## 相关文件

- `.github/workflows/pages-deploy.yml` — 新增 workflow_run 触发器和成功条件判断
- `.github/workflows/fund-info-sync.yml` — 移除 curl dispatch 步骤
