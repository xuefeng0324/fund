# v2.6.4 - 自动刷新间隔调整

**发布日期：** 2026-05-13

## 需求背景

自动刷新频率过高（2分钟）导致不必要的请求开销，调整为3分钟以降低服务器压力。

## 实现方案

修改 `src/App.vue` 中的 `REFRESH_INTERVAL` 常量，从 `2 * 60 * 1000`（2分钟）调整为 `3 * 60 * 1000`（3分钟）。

## 变更内容

### 功能优化
- 自动刷新间隔从 2 分钟调整为 3 分钟
- 更新 README 功能特性描述中的刷新间隔说明

### 涉及文件
- `src/App.vue` — 修改 `REFRESH_INTERVAL` 常量
- `README.md` — 更新版本信息和功能描述
- `package.json` — 版本号更新至 2.6.4
