# v2.7.0 — fundgz 失效修复 (FundValuationLast 接口迁移)

## 问题背景

用户反馈基金实时估值突然显示为空. 经探测发现根本原因是:
- **`fundgz.1234567.com.cn/js/{code}.js`** 自 2026-02 起被天天基金主动下架
- 项目旧数据源 JSONP 接口全部返回 404 HTML 页面
- 实时估值功能彻底无法使用

进一步追溯: 2026-02 证监会下发《机构监管通报》, 要求所有代销及非代销三方平台下架"基金实时估值/加仓榜/实盘榜"等功能, 涉及蚂蚁基金、京东金融、腾讯理财通、天天基金等. 因此这是**合规下架**, 不是技术故障.

## 修复方案

经过对 LeekHub/leek-fund issue #677 等开源方案的调研, 发现天天基金仍维护一个**只读估值接口**用于内部产品 (但字段严格, 半数基金 GSZ/GSZZL 为 null):

```
POST https://fundcomapi.tiantianfunds.com/mm/newCore/FundValuationLast
     (或 https://fundcomapi.eastmoney.com/mm/newCore/FundValuationLast)

Body (x-www-form-urlencoded):
  FCODES=001549,161725,510300
  FIELDS=FCODE,SHORTNAME,GSZZL,GZTIME,GSZ,NAV,PDATE,NAVCHGRT

Response:
  { "data": [{FCODE, SHORTNAME, GSZ, GSZZL, GZTIME, NAV, NAVCHGRT, PDATE}],
    "errorCode": 0, "success": true, "totalCount": 28468 }
```

**关键特性**:
- ✅ CORS 开放: `Access-Control-Allow-Origin: *`, 浏览器可直接 fetch
- ✅ 支持批量: 一次最多 500 个基金, 实测 53 个返回 145ms
- ✅ 字段完全兼容原 fundgz 输出 (FCODE/SHORTNAME/GSZ/GSZZL/GZTIME/DWJZ/SHORTNAME)
- ⚠️ 部分基金 GSZ/GSZZL 仍为 null (受合规限制: QDII/商品期货/主动管理型)

字段映射规则 (`mapFVItem`):

| FV 原始字段 | UI 字段 | 含义 |
|------------|---------|------|
| `FCODE` | `FCODE` | 基金代码 |
| `SHORTNAME` | `SHORTNAME` | 简称 |
| `GSZ` (盘中) | `GSZ` | 估算净值 (估) |
| `GSZZL` (盘中) | `GSZZL` | 估算涨跌幅 (%) |
| `GZTIME` (盘中) | `GZTIME` | 估值时间 |
| `NAV` | `DWJZ` | 上一交易日单位净值 |
| `NAVCHGRT` | — | 实际涨跌幅 (兜底时用) |
| `PDATE` | — | 净值日期 (用于判断 isUpdated) |

退化逻辑:
- **若 GSZ 非 null**: UI 显示 `GSZ/GSZZL/GZTIME` (盘中估算) + 标记 `_hasEstimated=true`
- **若 GSZ 为 null**: UI 显示 `NAV/NAVCHGRT` (上一交易日实际值) + `_hasEstimated=false` + `GZTIME=''`
- **完全无数据**: 进入 pingzhongdata 串行兜底

### `src/composables/useFunds.js`

`loadFunds` 流程重构:

1. **批量 FV 接口** → 一次性拿到 53 个基金的实时估值
2. **遍历** → 用 FV 直接给的 PDATE/DWJZ/GSZZL 计算 `isUpdated` (T+N 规则), 不再 pingzhongdata 拉每个基金
3. **兜底** → FV 完全失败 (null) 的基金走 pingzhongdata 串行

实测请求数对比:

| 数据源 | 旧 (v2.6.5) | 新 (v2.7.0) |
|--------|-------------|-------------|
| 实时估值 | 53 × JSONP 串行 (fundgz) | **1 × POST batch** |
| 历史净值 (isUpdated 判断) | 53 × pingzhongdata | **0** (用 FV 自带 PDATE) |
| 建议算法 (KDJ/MA30/MA60) | 53 × pingzhongdata | **不变** (useAdvice.js 需要 trend 序列, 无替代) |
| 指数 | 1 × push2 | **不变** |
| **总计基金 API 请求数** | **~160 次** | **53 次** |

加载速度提升约 **3 倍**.
